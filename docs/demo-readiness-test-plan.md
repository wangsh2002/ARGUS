# ARGUS 演示就绪测试矩阵

## 通过标准

- 严格页面：桌面端综合查询、IOC 详情、攻击组织、攻击链匹配/复核/详情、历史报告、情报图谱。
- 基础页面：情报入库只要求页面可达、表单可编辑、校验和失败提示正常，不以抽取质量作为演示阻断条件。
- 暂不验收：ARGUS GPT 与移动端布局。
- 严格用例必须同时满足：无空白页、无未处理异常、无失败 API、数据数量一致、返回导航正确、关键操作可重复。

## 自动化与人工验收

- 前端：生产构建、Vitest 交互测试、服务端渲染测试、ESLint。
- 后端：当前数据库 API 、AttackFlow 匹配、图谱、组织投影和来源一致性测试。
- 浏览器：桌面尺寸逐页点击严格用例。
- 阻断条件：任一严格用例失败、浏览器控制台出现未处理异常、关键 API 非 2xx，均不得标记为演示就绪。

## 当前验收结果

- 综合查询：9 类查询、精品推荐、历史研判报告与顶部返回首页通过。
- 攻击链：箭头单链只保留完整覆盖候选；组合告警稳定返回两条攻击流。
- 数据口径：49 条攻击流均有节点、边、证据和规范来源 ID；同一报告不再重复计数。
- 攻击组织：25 个画像均至少具备 1 条关系和 1 条关系级证据。
- 情报图谱：5 个精选起点均有真实邻域；高关联实体仅展示至少 2 条直接关系的节点。
- 自动化：前端构建/交互测试/SSR/lint 与后端完整测试通过后方可交付。
